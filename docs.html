Overview

Test Data Generator builds realistic fake data from a schema you define: add fields, pick a type for each, press download. Output is nested XML, JSON, or flat CSV. Everything runs in your browser — no server, no account, and no data leaves the page.

Quick start

  1. Add a field (or press Load example). Each card has the field name on top and the type picker below it.
  2. Click the type and start typing to search — built-in types plus the full Faker catalog.
  3. Watch the preview update as you edit (Ctrl/⌘+Enter refreshes on demand). Each card also shows a live sample value.
  4. Pick a format, set the row count, and Download.

Drag the dotted handle to reorder fields; the copy icon duplicates a field.

The catalog is read from the Faker build the app ships with, and only lists methods that work without arguments — that's how this tool calls them. Methods that require arguments (like date.between) are not listed; use a Date field or a formula instead.

Nesting, attributes & repeats

Structure lives in the field name, using three pieces of syntax:

SyntaxMeaningXML output
address.citydots nest elements<address><city>…</city></address>
order.@id@ on the last part makes an XML attribute<order id="…">
friend[3]repeat exactly 3×three <friend> elements
item[2-5]repeat a random 2–5× per record2–5 <item> elements

Shared counts: sibling fields under the same repeating segment share one count per record, so the parts of each repeated element line up. These two fields always produce the same number of orders:

orders.order[1-3].sku
orders.order[1-3].qty

In JSON that becomes:

"orders": { "order": [
  { "sku": "978-1-56619-909-4", "qty": 2 },
  { "sku": "978-0-7645-7682-9", "qty": 7 }
] }

One repeating segment per field path. In CSV, nested names become the column header and repeated values are joined with |.

Formulas (JS)

A Formula (JS) field is a JavaScript expression evaluated per record, after all other fields — so it can read them. Formulas run in field order, so a formula can also reference an earlier formula.

NameWhat it gives you
field('name')the value of another field (at the current repeat index, if repeated)
fields('name')the full array for a repeated field
ithe current repeat index (0-based) when the formula field itself repeats
rowthe whole record so far, keyed by field name
normalize(s)lowercase, strip everything but letters and digits
concat(a, b, …)join values into one string
pad(v, len, ch?)left-pad to a length, '0' by default
rand(min, max)random integer, inclusive — uses the seed

Any plain JavaScript works too: string methods, Math, ternaries, template literals. Formulas run in your own browser on data generated in the page — still, only paste expressions you trust.

Formula recipes

Copy these into a Formula (JS) field's expression box. They assume fields named first_name, last_name, etc. — change the names to match your schema.

Combining fields

// username: lenora.kuhlman
(field('first_name') + '.' + field('last_name')).toLowerCase()

// full name with a middle initial
field('first_name') + ' ' + field('middle')[0] + '. ' + field('last_name')

// normalize: lenorakuhlman (lowercase, letters and digits only)
normalize(field('first_name') + field('last_name'))

Changing case & shape

// UPPERCASE
field('city').toUpperCase()

// lowercase
field('city').toLowerCase()

// Capitalize Each Word
field('city').replace(/(^|\s)\S/g, c => c.toUpperCase())

// slug: port-angeles
field('city').toLowerCase().trim().replace(/[^a-z0-9]+/g, '-').replace(/^-+|-+$/g, '')

// initials: LK
(field('first_name')[0] + field('last_name')[0]).toUpperCase()

// trim whitespace
field('notes').trim()

IDs & codes

// padded code: CUST-000042 (uses a Row Number field named id)
'CUST-' + pad(field('id'), 6)

// random SKU: SKU-387
'SKU-' + pad(rand(1, 999), 3)

// numbered repeats: ITEM-1, ITEM-2, … (in a repeating field)
'ITEM-' + (i + 1)

Numbers & conditions

// price with 2 decimals: 214.55
rand(2000, 40000) / 100

// conditional label
field('qty') > 5 ? 'bulk' : 'single'

// sum a repeated field (use the sibling's full field name)
fields('orders.order[1-3].qty').reduce((a, b) => a + b, 0)

// weighted choice: ~80% active
rand(1, 10) <= 8 ? 'active' : 'inactive'

Seeds & reproducibility

Leave seed empty for different data on every run. Set a seed and the same schema + seed produces byte-identical output, every time, on any machine — useful for repeatable test suites. The preview shows which seed was used, so you can pin a result you like.

Schema files

Export schema saves your setup as JSON; Import schema loads it back. Keep one file per data model.

{
  "root": "records",          // XML root element
  "record": "record",         // XML per-row element
  "fields": [
    { "name": "first_name", "type": "First Name", "opts": {} },
    { "name": "iban", "type": "Faker (any)", "opts": { "method": "finance.iban" } },
    { "name": "username", "type": "Formula (JS)",
      "opts": { "expr": "(field('first_name')).toLowerCase()" } }
  ]
}

Limits: 10,000 rows per download (a browser-memory guardrail) and one repeating segment per field path.
