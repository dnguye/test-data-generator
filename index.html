Schema

Field naming: use dots to nest — address.city → <address><city>. Use @ on the last part for an XML attribute — order.@id. Use brackets to repeat — friends.friend[3] or a random range item[2-5].
Formulas are JavaScript. Reference other fields with field('name'). Helpers: normalize(s) (lowercase, strip non-alphanumerics), concat(a,b,...), pad(v,len), rand(min,max), and i (repeat index). Example: normalize(field('name') + field('nick'))
